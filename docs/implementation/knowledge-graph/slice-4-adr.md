# Traceability map user interface with Cytoscape

The human project authority approved a distinctive Knowledge Graph UI on
2026-07-29. The visual direction is an engineering traceability atlas: a dark
blueprint canvas, quiet off-white working surfaces, relationship evidence as
the signature detail, and compact utility typography. Cytoscape is rendering
only; query, validation, and source access remain owned by existing APIs.

The UI includes explicit refresh, search/filter, selectable nodes, incoming and
outgoing relationships, evidence, validation issues, fit/layout controls, and
source opening. Graph RAG and graph editing remain excluded.
