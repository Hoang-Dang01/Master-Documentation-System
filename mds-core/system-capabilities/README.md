# MDS system capabilities

Orchestrator, Knowledge Curator, Validator, and Context Builder are MDS
capabilities. They support governed workflows; they are not professional roles
or autonomous implementation authorities.

This directory classifies the capability boundary only. It does not introduce
agent contracts, implementation authority, or new runtime features.
