# Quality Assurance — Expected Outputs

- Test plan, test case và verification criteria `DRAFT`.
- Requirement-to-test coverage/traceability report.
- Affected-test assessment và validity transition proposal.
- Verification evidence review: `PASS`, `FAIL` hoặc `UNVERIFIED`, kèm
  source/version/timestamp.
- Definition of Done gap report và release-readiness recommendation.

QA recommendation không phải human release approval.
