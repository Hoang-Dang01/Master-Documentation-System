# Vai Trò BE — Kết Quả Đầu Ra

- API/DB/service/integration specification `DRAFT` theo canonical template.
- Backend impact assessment có graph path và source evidence.
- Validity transition proposal cho affected backend artifacts.
- Spec/implementation drift finding có expected/observed evidence.
- Backend implementation context có authoritative IDs/versions, constraints,
  acceptance criteria và open warnings.
- Verification review kết luận pass/fail/unverified dựa trên evidence.

Không output nào của vai trò này là managed-project source code.
