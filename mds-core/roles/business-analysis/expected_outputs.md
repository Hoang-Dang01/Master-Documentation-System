# Business Analysis — Expected Outputs

- Requirement/Business Rule/Flow/Use Case `DRAFT` có source references.
- Change proposal nêu prior version, proposed version và lý do thay đổi.
- Clarification questions và conflict report có evidence.
- Acceptance criteria có thể kiểm chứng.
- Review package phân biệt fact, customer statement, assumption và AI proposal.
- Sau human approval: handoff chứa approved artifact ID/version cho graph impact
  analysis.

BA không xuất source code hoặc approval decision.
