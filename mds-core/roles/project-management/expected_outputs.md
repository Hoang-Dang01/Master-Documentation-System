# Project Management — Expected Outputs

- Tài liệu phạm vi dự án và quyết định ưu tiên.
- Outcome Roadmap, Milestone và Release Plan.
- Epic breakdown theo vertical slice.
- Delivery board có task, acceptance criteria và dependency DAG.
- Risk Register và Blocker/Escalation Log.
- Báo cáo trạng thái dựa trên bằng chứng.
- Definition of Done/Release readiness report.
- Tài liệu bàn giao có thể tiếp tục ở phiên hoặc agent khác.

Template và validator chuẩn nằm tại
`skills/mds/mds-project-management/`.
