# External actors

This boundary holds the classification of people or organisations that supply
intent, process knowledge, confirmation, feedback, or change requests to MDS.

Customer / Stakeholder is the current external actor. It is not a professional
role, implementation authority, or approval gate. Its canonical definition is
in the role model and registry; this folder does not create a separate actor
contract or runtime feature.
