# DevOps & SRE Glossary

- **CI/CD:** Continuous Integration and Continuous Deployment. Practice of automating the integration of code changes and their deployment.
- **SLA:** Service Level Agreement. Commitment between a service provider and a client regarding service reliability and performance.
- **SLO:** Service Level Objective. Target reliability level defined inside an SLA (e.g. 99.9% availability).
- **SLI:** Service Level Indicator. A quantitative measure of the service level provided (e.g. actual measured error rate).
- **Canary Release:** Deployment strategy where a new version is released to a small subset of users before deploying it globally.
- **RTO / RPO:** Recovery Time Objective (max acceptable downtime duration) and Recovery Point Objective (max acceptable data loss age).
