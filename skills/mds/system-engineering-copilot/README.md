# System Engineering Copilot (AI-EOS)

Welcome to the **AI Engineering Operating System (AI-EOS)**, a Level 3 modular enterprise framework for orchestrating the Software Development Life Cycle (SDLC).

## Overview

Unlike a single-prompt helper, this framework behaves as a coordinated team of virtual engineering specialists. It manages state across conversation boundaries, runs semantic validations on diagrams, consults a structured knowledge index, and applies architectural principles dynamically.

## How to Trigger

Ask your AI coding assistant to design a system, review an architecture, write API/DB contracts, or map DevOps pipeline topologies. The system engineering copilot will automatically wake up and guide you through the appropriate execution modes.

## Modes of Operation

1. **Discovery Mode**: Intake of raw, sketchy requirements. Asks structured clarification questions.
2. **Generate Mode**: Sequential generation of enterprise docs and Mermaid diagrams (BA, SA, Tech Design, Testing, Release).
3. **Review Mode**: Audits existing architectures and lists risks/smells.
4. **Update Mode**: Dynamic impact assessment and delta updates on existing designs.
